# connectors（ブラウザ操作の接続メモ）

Mac 上の Chrome を Playwright MCP 経由で操作するための、接続メモとクライアントです。

**このブラウザ操作は 2026-11-04 から無効化されています（本人の明示的な指示）。** launchd エージェントは無効化＋boot out 済み、サーバは停止し、ポートは閉鎖されています。本人が明示的に解除を依頼した場合を除き、使わないこと・再起動しないこと。以下の記述は構築時点の記録です。GUI 送信の標準経路は `tools/gui_flow/` の `gui_flow.py`（LINE／Discord のネイティブアプリ操作）です。

専用プロファイルの Chrome を使い、画面に表示した状態（headed）で操作します（構築時点の記録）。接続先は Tailscale の内側だけに限定されています。

※ 公開版では、接続先のアドレスなどの実値はコードに直書きせず、環境変数（MAC_PLAYWRIGHT_HOST）やローカル設定に分離してあります。
